## 🛠️ Tech Stack
 
- **HTML5** — semantic sectioning (`<nav>`, `<main>`, `<section>`, `<footer>`)
- **CSS3** — Flexbox layout, CSS custom transitions, no external framework
- **Google Fonts** — [Inter](https://fonts.google.com/specimen/Inter)
- **Font Awesome** (via kit script) — social media and UI icons
